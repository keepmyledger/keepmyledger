# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report privately to:

- security@keepmyledger.org

Include as much detail as possible:

- affected version / commit
- reproduction steps
- impact assessment
- potential fix (if known)

We aim to acknowledge reports within 5 business days and provide regular status
updates until resolution.

## Supported versions

This project is best-effort maintained. Security fixes are usually shipped for
`main` first. Backports to older tags are evaluated case-by-case.

## Disclosure policy

After a fix is released, maintainers may publish a short advisory describing:

- affected components
- severity and impact
- patched version
- mitigation steps
